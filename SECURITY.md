# Security & Data Privacy Policy — FinGuard AI

## Synthetic Data Guarantee
- FinGuard AI operates exclusively on **100% synthetic and anonymized financial transaction data**.
- Zero real customer PII, bank account numbers, Aadhaar/PAN details, or live banking credentials are stored, transmitted, or processed.

## Application Security Controls
- **Client-Side Sandbox Execution:** Runs without external unverified API endpoints or hardcoded secrets.
- **Input Validation & Sanitization:** All user-supplied fields in the Custom Transaction Risk Simulator are strictly type-checked, numeric-clamped, and sanitized prior to DOM rendering to prevent XSS injection.
- **Auditability & Compliance:** Every high-risk alert generates a timestamped Suspicious Activity Report (SAR) aligned with FIU-IND / PMLA compliance workflows.
